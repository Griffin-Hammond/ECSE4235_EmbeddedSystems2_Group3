The iPhone app

A single SwiftUI screen that connects to the Raspberry Pi over Bluetooth Low Energy (CoreBluetooth), sends commands, and shows what the Pi reports back.

Screenshots

What is on the screen

Feedback line

At the top: the result of the last action, with a red warning icon when something was refused.

Bluetooth

Connect to PARMCO / Disconnect, with a coloured indicator: green connected, yellow searching or connecting, grey off.

Motor

A large Start/Stop button, a Clockwise/Counterclockwise switch, and Slower/Faster buttons.

Desired speed

RPM entry with Set RPM. Only 10–100 is accepted; anything else gets a red outline and "Invalid", and is never clamped. An over-range unlock for tests B and G switches off when the motor stops.

Mode

Manual or Maintain speed control.

Position

Calibration status, Calibrate zero, Set to zero, and an angle target. The last two are dimmed and refuse with a warning until the Pi reports calibrated.

Logging

An optional test label, Start/Stop logging, and while logging a red dot with the log file name from the Pi and the elapsed time.

Status from RP4

IR RPM, encoder RPM, encoder angle, calibration, commanded speed and direction, H-bridge enabled or disabled, and how long ago the last update arrived.

Messages

Every command sent (→) and every reply received (←), newest first, with time stamps; ERR replies in red.

Behaviour the specification asks for

  • On every connection the controls reset to the defaults: Manual, clockwise, 20 RPM, stopped, not calibrated.
  • Every control responds visibly, connected or not.
  • Status fields the Pi has not sent show "—".
  • The app notes when it goes to the background or comes back, so a dropped connection can be matched with the phone locking.

Checkpoint 3: the app is the only control input. It shows the Pi's state (running, moving to an angle, holding), lost steps, hold corrections and the log file name with its elapsed time, and its controls follow what the Pi reports, for example the unlock switching off by itself when the motor stops.
