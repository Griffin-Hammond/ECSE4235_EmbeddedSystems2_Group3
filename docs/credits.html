Libraries and tools

NameLicenceUsed byWhat it does for PARMCO
ECSE 4235 class library libE4235 Class library, provided by the instructor and class (not AI) Pi program: hbridge.s, IR code ARM assembly routines that memory-map the GPIO registers and set pin functions and levels (E4235_Init, E4235_Select, E4235_Write, E4235_Read). The project requires all GPIO access to go through it.
Binc (weliem/bluez_inc), by Martijn van Welie; vendored unmodified at commit 157c604 MIT Pi program: ble.c Publishes the advertisement, GATT service and characteristics as the D-Bus objects BlueZ needs for the peripheral role, and calls the program when the phone writes or subscribes.
GLib / GIO LGPL-2.1-or-later Pi program, Binc Event loop, timers and the D-Bus client Binc is built on.
BlueZ (bluetoothd) GPL-2.0, part of Raspberry Pi OS System service The Linux Bluetooth stack: runs the radio and turns the program's D-Bus objects into a real BLE advertisement and GATT server.
POSIX threads, glibc LGPL Pi program Threads, mutexes, the monotonic clock and real-time scheduling.
SwiftUI Apple SDK iPhone app The user interface.
CoreBluetooth Apple SDK iPhone app The BLE central role: scanning, connecting, writing and notifications. The only way an iOS app can use Bluetooth Low Energy.
XcodeGen (yonaskolb/XcodeGen) MIT Build tool only Generates the Xcode project from project.yml, so the project stays reviewable as text.
schemdraw, Python-Markdown, headless Google Chrome MIT, BSD, Google terms Documentation only Draw the schematic and build the hardware PDF.
