Software

The RP4 program is written in C, with the H-bridge interface in ARM assembly. The full AI-written documentation, including library attribution and code flags, is in the software documentation.

Threads

ThreadPriorityJob

ControlSCHED_FIFO 15Every 5 ms: reads the latest encoder value, runs the commands and the mode state machine, and hands one row to the logger

The control thread owns all motor state, so a phone command never drives the motor directly. If the phone disconnects, the control thread stops the motor.

Assembly interface

The H-bridge routines are in hbridge.s and call the class library for every GPIO access: HB_Init, HB_Enable, HB_Step, the timed loop HB_RunSteps, and, new at Checkpoint 3, HB_SetIndex and HB_GetIndex. The last two choose a coil pattern without stepping. The feedback hold needs them to restart on the pattern that matches the encoder.

Measuring speed and angle

  • IR RPM. One revolution is the time from a blade back to the blade two pulses earlier, so differences between the blades cancel. The value is the median of the last three revolutions and reads 0 after four seconds without a blade.
  • Encoder angle. Calibrate zero stores the current encoder reading as 0°. The angle is unwrapped across turns by taking the shortest way round between 5 ms readings.
  • Encoder RPM. The change in unwrapped angle over a 0.5 s window. At 20 RPM that is 60° of travel, so encoder noise stays below 0.2%.
  • Encoder bus. The class library’s I2C module hung on our RP4, so the program drives the I2C bus itself through the library’s GPIO calls, with every acknowledge checked and every wait limited to 1 ms.

Control modes

Mode or featureHow it works
ManualFaster, slower and desired RPM change the step rate directly. Faster and slower change it by 3%, and above 100 RPM is refused unless the over-range unlock is on.
Position movesAngle targets and set to zero take the shortest way, measured by the encoder, and correct with up to two extra moves if the blade is a step or more off. Because the encoder is the reference, set to zero still works after lost steps.
Feedback holdAfter a move the coils are switched off. If the encoder shows the blade more than 1° away for three readings in a row (15 ms), the program sets the coil pattern that matches the encoder, re-enables, moves back and switches off again.
MaintainA sync supervisor restarts the motor at 60% speed if the rotor loses step, and a slow PI trim on the encoder RPM corrects the rate by at most ±15%. Maintain is checked at the final check.

Logging

Turning logging on opens CP3/logs/log_YYYY-MM-DD_HH-MM-SS[_label].csv, with one row every 5 ms (200 Hz). Rows are stamped from the Linux monotonic clock, and a full buffer drops and counts rows instead of making the control loop wait.
